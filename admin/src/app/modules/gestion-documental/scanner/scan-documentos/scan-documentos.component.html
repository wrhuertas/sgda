Esta computadora no tiene conexión con el escáner

Para que el sistema pueda abrir el escáner, primero hay que descargar este archivo e instalarlo en esta computadora. Se hace una sola vez y no necesita permisos de administrador.

  1. Use el botón Descargar conexión al escáner de arriba.
  2. Ábralo con doble clic y espere el mensaje de confirmación.
  3. Vuelva acá y toque otra vez Abrir escáner.

El navegador puede avisar que el archivo no es habitual: elija Conservar y luego ábralo.
